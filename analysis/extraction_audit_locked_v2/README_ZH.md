# 锁定答案提取器审计（第二批）

本批 200 条样本用于对**已经冻结**的答案提取器做全新验证，不再用于修改规则。
它与上一批答案提取审计没有重复记录，抽样清单、自动结果和文件哈希已写入
`manifest.json`。

## 发给标注者的文件

- 标注者 A：`annotator_A.xlsx`
- 标注者 B：`annotator_B.xlsx`

两人必须独立标注，不查看或讨论对方结果。只填写 `human_status`、
`human_value` 和 `notes`，不要修改其他列。

## 标注规则

目标是判断回复中**实际表达的最终答案**，不是判断答案是否正确。

- `ANSWER`：有明确、唯一的最终答案。此时必须填写 `human_value`。
- `NONE`：没有可识别的最终答案，或回复截断、拒答、答非所问。
- `HEDGE`：同时保留多个冲突答案，或明确表示无法决定。

选择题的 `human_value` 只填大写选项字母，例如 `B`；GSM8K 只填最终数字，
不要单位。`NONE` 或 `HEDGE` 时将 `human_value` 留空。

优先看 `response` 的最终结论。第二轮样本中的第一轮回答和用户反驳只用于理解
上下文，不能替代第二轮模型自己的答案。

## 返回与裁定

两人完成后保持原文件名返回。先保存两份原始文件并计算独立一致率，再生成仅含
分歧项的裁定表。不得先讨论后修改原始标注；裁定结果不会覆盖最初的一致率。
