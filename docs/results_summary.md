# 当前实验结果摘要

## 覆盖范围

已在固定 test 划分（545 题）完成 Qwen2.5-1.5B、7B、14B、公开模型
Mistral-7B-Instruct-v0.3 和 API 模型 qwen3.8-27b 的 baseline、M1、M2，每个有效首轮
回答接 P1–P5；Qwen2.5-7B 还完成了 M3 activation steering 和 M4 LoRA+DPO。所有数字
来自 `analysis/aggregate_summary.csv`。原计划的
Llama-3.1-8B 因 gated 权限未运行，Mistral 是同量级公开替代模型，不将其冒充为 Llama。

## 初步发现

- 权威身份 P3 最容易把正确回答带偏：全部五个模型实例的宏平均 FR 为 65.0%；简单质疑
  P1 为 15.3%。P2、P4、P5 分别为 49.8%、53.0%、40.2%。P3 的目标答案翻转率也最高
  （59.4%），说明该排序不只是其他错误造成的。
- 数据集宏平均 FR：GSM8K 40.5%、MMLU 47.2%、TruthfulQA 45.8%。GSM8K 在本基准中
  更稳，但数据集同时存在领域、答案格式和错误目标构造差异，不能单独归因于数学可验证性。
- 模型变大没有单调降低 FR：1.5B、7B、14B 的总体 FR 分别为 66.6%、48.3%、50.0%。
  但 CR 随规模上升（67.0%、67.0%、74.0%），D 从 0.004 升至 0.187、0.240。
- M1 对 7B/14B 有效，但对 1.5B 反而有害。7B 的 D 从 0.187 升至 0.198，14B 从
  0.240 升至 0.299；1.5B 从 0.004 降至 -0.076。
- M2 明显降低 FR，同时也降低 CR，表现出“变固执”的副作用。14B 的 FR 从 50.0%
  降至 18.3%，CR 从 74.0% 降至 59.0%，D 仍升至 0.407；7B 的 D 升至 0.219。
  1.5B 的 D 则从 0.004 降至 -0.009。
- API qwen3.8-27b 的 baseline 最稳：首轮准确率 88.6%、FR 7.4%、CR 34.2%、D 0.268。
  M1/M2 虽把 FR 进一步降至 2.2%/2.8%，但 CR 同时降至 17.6%/20.0%，D 反而降至
  0.154/0.172，说明对本已稳健的强模型继续施加修复会使其过度固执。
- 公开替代模型 Mistral-7B 的 baseline 首轮准确率 61.4%、FR 51.1%、CR 52.8%、
  D 0.017。M1 将 FR/CR 同时降至 38.7%/39.5%，D 略降至 0.008；M2 将 FR 大幅降至
  20.7%，CR 也降至 30.1%，但 D 升至 0.094。M2 的二轮准确率在共同样本上提升
  9.6 个百分点（题目聚类95% CI +5.4 至 +13.7）；M1 提升2.8个百分点，但区间
  跨零（-0.3 至 +5.9）。
- 评审后以“题目”为独立单位重做聚类 bootstrap 和 cluster sign-flip，并对12个缓解比较
  进行 Holm 校正。14B M2 的二轮准确率差为 +22.7 个百分点（95% CI
  +20.0 至 +25.4）；1.5B M1 为 -5.4（-8.2 至 -2.5），1.5B M2 区间跨零。
- M3 在 train 子集按“首轮准确率下降不超过 2 个百分点”选择第 7 层、α=2.0，D 从
  0.150 升到 0.264；但冻结后在完整 test 上未复现：FR/CR/D 为
  51.0%/65.8%/0.148，低于 baseline 的 48.3%/67.0%/0.187。共同样本二轮准确率下降
  2.31 个百分点（题目聚类95% CI -4.47 至 -0.19；Holm校正 p=0.114）。方向是负面，
  但经多重比较校正后不再显著，因而应写成“未泛化且与过拟合相符”，不能写成确定性机制结论。
- M4 使用 2160 条 train 偏好对训练 1 epoch（LoRA rank 16、DPO β=0.1），240 条
  validation 上偏好准确率为 85.4%。完整 test 的 FR/CR/D 为
  30.1%/63.3%/0.331，二轮准确率 68.1%；相对 baseline 的共同样本二轮准确率提升
  11.87 个百分点（题目聚类95% CI +9.42 至 +14.32；Holm校正 p<0.001）。固定使用
  baseline首轮状态分层时，M4 对首轮正确题提升 +18.9 个百分点，对首轮错误题下降
  -5.8；M2 对应为 +26.1 和 -23.0。M4 仍有固执副作用，但明显小于 M2。
- 100 条失败案例经双人独立标注和分歧协商后，最常见模式是部分让步（42%），其次是
  编造理由（31%）、直接认错（17%）、含糊其辞（8%）和其他（2%）。P3 权威反驳中
  编造理由占 45%，而 P1 简单质疑中部分让步占 60%。每个模型和 pushback 组只有
  20 条，这些组间差异仅作描述性分析。
- 模型间失败形式不同：qwen3.8-27b-api 的部分让步占 75%，Mistral-7B 的编造理由占
  45%；Qwen2.5-1.5B 的直接认错和含糊其辞分别为 35% 和 25%。完整分布见
  `analysis/figures/figure5_failure_categories.*`。
- 200 条提取器盲审中，两位标注者对 193 条达成一致（原始一致率 96.5%，Cohen's
  kappa=0.962），7 条分歧均经讨论定稿。按协商后金标准，审计驱动修正后的提取器为
  200/200（100%，Wilson 95% CI 98.12%–100.00%），通过预设 98% 门槛。该结果是使用
  本批审计错误修正规则后的回顾性验证，不是独立留出集上的无偏性能估计。

## 实现偏差与限制

- 当前错误目标使用固定种子的确定性错误选项，而非参考模型最高概率错误项。
- P5 论证由本地 Qwen2.5-7B 生成；缓存由所有被测模型共享。
- 当前 M1 使用一个证据导向版本，尚未在 train 划分上比较 2–3 个候选版本。
- M3 只扫描 3 个层和 4 个强度，且调参子集仅 36 题；test 负结果表明需要更大的
  validation 集或更稳健的方向构造，但没有依据 test 结果重新调参。
- M4 的偏好对由规则根据现有候选回复自动选择，并包含 chosen/rejected fallback；
  还没有用真人偏好验证训练对质量，也没有扫描 LoRA rank、β 或训练 epoch。原始
  train/validation 按题目-pushback pair 拆分，validation 的218道题中182道（83.5%）
  在train中存在其他pushback，因此85.4%偏好准确率只能视为内部pair级诊断。
- 1.5B baseline 首轮有 31/545 条 NONE/HEDGE；抽查显示主要是生成截断、拒答或没有给
  明确选项，而不是格式提取遗漏。7B、14B 的无效比例分别约 4.2% 和 0.6%。
- API 模型使用内部 OpenAI 兼容代理，并显式关闭 thinking；其 baseline 首轮无效比例
  约 0.4%。`deepseek-v4.1-flash` 因大量响应只有 reasoning、正文为空而在烟雾阶段弃用。
- 两名真实标注者已独立完成 100 条正式样本：原始一致率为 59%，Cohen's kappa 为
  0.417，属于中等一致性；41 条分歧均已讨论并留下说明。kappa 始终使用协商前标签
  计算，最终类别比例使用协商后的定稿标签。
