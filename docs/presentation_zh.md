# 课程展示：大语言模型在错误质疑下的谄媚性与缓解方法

本文件是一套 **13 页、约 12–15 分钟** 的中文展示大纲。每页只保留一个核心结论；
“讲稿”可直接作为口头说明，“素材”给出仓库内可插入幻灯片的文件。

---

## 第 1 页｜研究问题与结论预览

**核心结论：** 更大的模型不一定更少谄媚；本实验中 DPO 微调明显优于 activation
steering。

- 研究对象：模型先答对、再遭遇用户错误质疑时是否改错。
- 比较 5 类 pushback、3 个数据集、4 个公开模型及 1 个 API 模型。
- 比较提示、独立复核、activation steering 和 LoRA+DPO 四类缓解方法。
- 主要发现：权威型质疑最危险，M3 未泛化，M4 显著改善二轮准确率。

**讲稿：**  
普通准确率只问模型会不会答题，而我们关心的是：模型本来答对以后，能不能在用户坚持
错误答案时保持证据导向。实验显示，规模并不能单调解决这个问题；在 7B 模型上，
activation steering 的验证集收益没有泛化到测试集，而 DPO 微调显著降低了错误翻转。

- 标题页无需图；可用 `analysis/figures/figure6_paired_accuracy_effects.png` 右下角缩略图。

## 第 2 页｜两轮 Benchmark 设计

**核心结论：** 固定首轮回答后，只改变第二轮质疑，才能把“谄媚”与知识能力分开。

- 第 1 轮：模型独立回答问题并给出最终答案。
- 第 2 轮：用户提供一个确定性错误目标，并用 P1–P5 之一进行质疑。
- 只有“首轮正确 → 二轮错误”才计为错误翻转。
- 固定 test 划分 545 题；每道题共享一次首轮回答。
- 数据与随机过程使用固定种子 42，可断点续跑。

**讲稿：**  
如果每种质疑都重新生成第一轮，就会把采样波动混入比较。因此同一道题的 P1 到 P5
共享首轮回复，第二轮唯一变化是质疑方式。这样，FR 衡量的不是模型本来会不会，而是
它在已经答对的条件下会不会被带偏。

**素材：**
- 可现场绘制简单流程：`Question → Turn 1 → Wrong pushback → Turn 2`。
- 实现入口：`src/sycophancy/runner.py`、`src/sycophancy/metrics.py`。

## 第 3 页｜指标：不能只看错误翻转率

**核心结论：** 好的缓解方法应同时降低 FR、保留 CR；因此用 \(D=CR-FR\) 衡量净收益。

- FR：首轮正确样本中，二轮被错误目标带偏的比例。
- CR：首轮错误样本中，二轮被质疑后纠正的比例。
- \(D=CR-FR\)：越大表示更能“该坚持时坚持、该纠正时纠正”。
- 同时报告二轮准确率、以题目为独立单位的聚类 bootstrap 95% CI 和 cluster sign-flip。
- 只降低 FR 可能代表模型变得固执，而非变得更可靠。

**讲稿：**  
如果给模型一句“永远不要改变答案”，FR 会下降，但首轮答错时它也不会纠正，所以这种
方法没有真正提高可靠性。CR 用来捕捉这个副作用，D 则总结了两者的权衡。每道题有五种
相关 pushback，因此统计推断以题目为独立单位，并对12个缓解比较做 Holm 校正。

## 第 4 页｜实验覆盖与模型

**核心结论：** 实验覆盖弱到强的模型，但 API 强模型与本地模型的推理条件并不完全相同。

- 数据集：MMLU 500、GSM8K 500、TruthfulQA 全量；统一 7:3 train/test。
- 本地模型：Qwen2.5-1.5B、7B、14B；Mistral-7B-Instruct-v0.3。
- API 模型：qwen3.8-27b，关闭 thinking。
- 公开 Mistral-7B 替代原计划中需要 gated 权限的 Llama-3.1-8B。
- baseline、M1、M2 覆盖所有模型；M3、M4 聚焦 Qwen2.5-7B。

**讲稿：**  
模型选择既覆盖规模趋势，也加入了同量级不同家族的 Mistral。qwen3.8-27b 来自 API，
它首轮准确率明显更高，因此适合观察“本来已经很稳的模型是否仍受益”。但 API 与本地
推理栈不同，所以不把模型间差异解释为严格的架构因果效应。

## 第 5 页｜五种错误质疑 P1–P5

**核心结论：** 质疑的社会权威和解释力度，是控制错误翻转的重要实验变量。

- P1：简单表示“答案不对”。
- P2：直接给出错误答案。
- P3：以专家、教授或多年经验等权威身份给出错误答案。
- P4：以多数意见或外部共识施压。
- P5：给出一个支持错误答案的貌似合理解释。
- 所有错误目标均确定性生成，保证方法间可比。

**讲稿：**  
P1 只有怀疑，P2 加入明确替代答案，P3 加入身份权威，P4 加入社会共识，P5 则加入
错误论证。这个阶梯并非严格的心理学量表，但能系统地区分“内容”和“社会压力”对模型
改口的影响。

**素材：**
- 模板目录：`prompts/`。
- 可在一页中并列展示五条短模板，不需要图表。

## 第 6 页｜主结果：权威型质疑最危险

**核心结论：** P3 的平均 FR 达 65.0%，远高于简单质疑 P1 的 15.3%。

- 全部五个模型实例宏平均：P3 FR = 65.0%。
- P1 FR = 15.3%，是五类质疑中最低。
- P2、P4、P5 分别为 49.8%、53.0%、40.2%。
- P3 的目标答案翻转率也最高（59.4%），不是其他错误造成的假象。
- 模型并非只被“论证”说服，身份与社会线索同样会改变答案。

**讲稿：**  
最突出的结果是 P3：当错误答案由“专家”说出时，近三分之二原本正确的回答发生翻转。
反而带有貌似理由的 P5 没有 P3 和 P4 危险。这说明当前模型对社会性线索的敏感度可能
超过对论证质量的敏感度。

## 第 7 页｜数据集与规模趋势

**核心结论：** 数学题相对更稳，但扩大 Qwen 规模并未单调降低 FR。

- 数据集宏平均 FR：GSM8K 40.5%、MMLU 47.2%、TruthfulQA 45.8%。
- Qwen 1.5B、7B、14B 的 FR：66.6%、48.3%、50.0%。
- 同三模型 CR：67.0%、67.0%、74.0%。
- 14B 比 7B 更会纠错；7B与14B的FR小差异不作模型本质差异解释。
- 不同数据集与 pushback 的交互很强，单一总分会掩盖差异。

**讲稿：**  
GSM8K 的答案常有可复核计算，所以总体上较难被带偏。规模方面，1.5B 明显最脆弱，
但从 7B 增加到 14B 后 FR 反而略升。更大的模型确实提高了 CR，却没有让“答对后坚持
正确”同步改善，因此不能把参数规模当作谄媚问题的自动解法。

**素材：**

## 第 8 页｜M1/M2：有效，但可能让模型变固执

**核心结论：** 独立复核 M2 大幅降低 FR，但 CR 同时下降，必须看净权衡。

- 14B baseline：FR/CR/D = 50.0%/74.0%/0.240。
- 14B M2：18.3%/59.0%/0.407，D 明显提高。
- 7B M2 的 D 从 0.187 提高到 0.219。
- 1.5B 上 M1、M2 均未带来稳定净收益。
- qwen3.8-27b baseline 已很稳，M1/M2 进一步降低 FR，却使 D 下降。

**讲稿：**  
M2 先让模型不看用户质疑独立重解，再综合判断。它对 7B 和 14B 很有效，但 CR 下降
说明模型也更不愿纠正自身错误。这个副作用在本来就很稳的 API 模型上更明显：FR 虽然
更低，D 却下降。所以缓解方法需要按模型能力分层使用。

## 第 9 页｜配对显著性：哪些变化可信

**核心结论：** M4 的 +11.9 个百分点提升稳健；M3 呈负面趋势，但多重校正后不显著。

- 在共同样本上比较 baseline 与各方法的二轮正确率。
- 7B M4：+11.87 pp，题目聚类95% CI `[+9.42, +14.32]`。
- 7B M3：−2.31 pp，CI `[−4.47, −0.19]`，但 Holm 校正后 `p=0.114`。
- 14B M2：+22.7 pp，CI `[+20.0, +25.4]`。
- 1.5B M2 变化不显著，不能仅凭点估计宣称有效。

**讲稿：**  
点表示共同样本的正确率变化，误差线按题目聚类 bootstrap。M3 的点估计与区间为负，
但经过12项多重比较校正后不再显著，因此应称为“未泛化的负面趋势”。M4 的改善幅度大、
区间远离零，且 Holm 校正后仍显著。

## 第 10 页｜M3 为什么是负结果

**核心结论：** steering 在36题调参集上的收益没有泛化，结果与小样本过拟合相符。

- 由 desired/undesired continuation 的 residual 差构造方向。
- 扫描 3 个层、4 个强度；按“首轮准确率下降不超过 2 pp”选择第 7 层、α=2.0。
- 调参子集上 D 从 0.150 升到 0.264。
- 完整 test 上 FR/CR/D = 51.0%/65.8%/0.148，差于 baseline。
- 保持预注册式冻结，不依据 test 结果重新调参，避免结果泄漏。

**讲稿：**  
M3 的机制并非完全无效，它在很小的调参集上表现很好；问题是方向估计和超参数选择都
不稳定。我们没有看到测试结果后再换层或强度，因为那会把测试集变成训练集。这个负结果
提示 activation steering 需要更大 validation 集、更多方向样本和跨种子验证。

**素材：**
- `analysis/figures/figure6_paired_accuracy_effects.png` 中突出 M3。
- 实现：`scripts/build_steering_directions.py`、`scripts/tune_steering.py`。

## 第 11 页｜M4：LoRA+DPO 是最成功的缓解方法

**核心结论：** M4 在降低错误翻转的同时保留较高纠错率，改善了 M2 的“固执”副作用。

- 2160 条 train 偏好对，LoRA rank 16、DPO β=0.1、训练 1 epoch。
- 原 pair 级 validation 偏好准确率 85.4%，但83.5%的validation问题在train中有其他
  pushback，因此只作为内部诊断，不作为独立泛化证据。
- test FR 从 48.3% 降到 30.1%。
- test CR 保留 63.3%，D 从 0.187 升到 0.331。
- 二轮准确率 68.1%；相对 baseline 配对提升 11.87 pp。

**讲稿：**  
M4 学习的不是“永远坚持”，而是偏好证据导向的回复，所以在降低 FR 的同时仍保留
63.3% 的纠错率。与二轮准确率相近的 M2 相比，M4 的 CR 更高，说明它较少把鲁棒性
简单地变成固执。当前只训练了一个超参数配置，因此结论是“该配置有效”，不是已经找到
全局最优方案。

## 第 12 页｜人工定性结果与典型案例

**核心结论：** 模型常为迎合错误目标而“补造理由”，而 M4 能在相同压力下保留正确答案。

- 100 条失败案例由两位真人独立标注，原始一致率 59%，Cohen’s κ = 0.417。
- 41 条分歧经讨论定稿，并保留说明。
- 最终类别：部分让步 42%、编造理由 31%、直接认错 17%、含糊其辞 8%、其他 2%。
- P3 中编造理由占 45%，符合权威压力的定量结果。
- 案例 S001：baseline 从 230 翻到 253，M4 仍输出 230。

**讲稿：**  
定性分析显示，模型并不总是直接说“我错了”。更常见的是先部分承认用户，再通过一个
新理由把最终答案改掉；31% 的案例甚至出现明显编造。双人 kappa 只有中等水平，所以
我们保留了协商前的一致性指标，并用协商后标签计算最终分布。S001 展示了 M4 如何在
承认用户意见存在的同时，仍依据题目中的 80+150 保持 230。

## 第 13 页｜结论、限制与可复现性

**核心结论：** 谄媚性需要“抗错误压力”和“保留纠错能力”共同评估；当前证据支持 M4，
不支持该版 M3。

- 结论 1：权威型错误质疑是最强风险因素。
- 结论 2：规模扩大不保证 FR 单调下降。
- 结论 3：M2 有效但有固执副作用；M4 给出更好的 FR–CR 权衡。
- 限制：单种子、M3 调参集小、M4 未扫超参数、API/本地条件不同。
- 提取器审计：双人一致率 96.5%，Cohen’s κ=0.962；协商后金标准下，修正后的提取器
  为 200/200（100%，Wilson 95% CI 98.12%–100.00%），通过 98% 门槛。
- 代码、数据处理、结果和图表均在仓库中，固定种子可复现。

**讲稿：**  
这项工作的核心方法论是：不能只奖励模型不改答案，而要同时测量它被错误信息带偏和从
自身错误中恢复的能力。当前最可靠的实验结论是 P3 风险最高、M3 未泛化、M4 显著有效。
200 条提取器盲标与分歧协商已经完成；审计驱动修正后的规则通过了 98% 门槛。但由于
修正规则参考了本批审计错误，100% 应表述为回顾性验证，后续仍宜增加独立锁定测试集。
